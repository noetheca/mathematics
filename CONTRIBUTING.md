# Contributing

The content license has not yet been approved. External pull requests are not
currently accepted.

When contributions open, submitted prose, diagrams, and knowledge metadata will
be provided under the content license recorded by this repository. Shared
engine code belongs in `noetheca/knowledge-engine` under its separate code
license.

Do not submit copied text, images, exercises, or diagrams without verified
compatible permission. AI-assisted drafts require human review of facts,
sources, relationships, and licensing.

# 記事フォーマット検証サンプル

このディレクトリは、[数学記事フォーマット指南書](../../article-writing-guide-ja.md)をsubagentが単独で読んだとき、分野の異なる記事が一貫した形式で書けるかを確認するための検証用コンテンツである。

公開用の概念カタログではない。各記事は `status: draft` とし、数学的・教育的な最終レビューを終えた公開記事として扱わない。

試作の方法、見つかった問題、指南書へ反映した変更は[検証レポート](./REPORT.md)にまとめている。

検証では次を確認する。

- `concept.yaml` とlocale Markdownのスキーマ
- 冒頭文、説明、例題、任意の練習問題という構成
- 数式、単位、ルビ、directiveの契約
- 定義、定理、統計、公理・論理の記事種別への適応
- raw HTML、MDX、未登録interactiveを使わないこと
- 分野が変わっても、数学的条件・例・反例が明確であること

検証コマンドは、リポジトリのルートから次を実行する。

```sh
pnpm --dir mathematics validate:format-samples
```

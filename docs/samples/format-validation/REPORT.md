# 記事フォーマット試作検証レポート

## 目的

[数学記事フォーマット指南書](../../article-writing-guide-ja.md)をsubagentが単独で読んだとき、記事種別が変わっても一貫した下書きを作れるかを確認した。公開記事の内容審査ではなく、指南書と記事フォーマットの再現性を調べるための検証である。

## 方法

四つの担当を並行させ、各担当には指南書を読んだうえで、別の担当の記事を参照せずに一記事ずつ作成させた。その後、執筆を担当していないsubagentが、数学的正確性、構成、ルビ、数式、強調、安全な記法を横断してレビューした。

| 記事 | 種別 | 読解水準と理由 | 主に確認した点 |
| --- | --- | --- | --- |
| [偶数と奇数](./even-and-odd/ja.md) | 定義 | 小学3年。低学年の読者にも届く語彙とルビを試すため | 定義の範囲、境界例、非例、低学年向けルビ |
| [三角形の内角の和](./triangle-angle-sum/ja.md) | 定理 | 小学5年。記事が扱う学校算数の内容に合わせるため | 条件、証明の見通し、詳細の折りたたみ、証明図 |
| [算術平均](./arithmetic-mean/ja.md) | 初等統計 | 小学5年。記事が扱う学校算数の内容に合わせるため | データの個数、単位、代表値の限界、反例 |
| [等号の推移律](./equality-transitivity/ja.md) | 公理・論理 | 省略。特定学年の学校算数に限定せず、形式的な一般概念を試すため | 定義・公理・定理の区別、対象範囲、反例 |

すべて検証fixtureであり、`status: draft` としている。カタログ外の概念IDを参照しない単独検証のため、`prerequisites` と `related` は空配列にした。

## 結果

四記事とも、冒頭の一文、`## 説明`、1〜2題の例題、任意の練習問題という基本構成を再現できた。必要な式を記事用数式記法で書き、解答や長い証明を `details` に収め、raw HTML、MDX、未登録interactiveを使わないという技術契約にも従えた。

一方、初稿には次の問題があり、レビュー後に修正した。

- 偶数と奇数: 整数の説明から負の整数が抜けていた。
- 三角形の内角の和: 証明中の角の位置が文章だけでは追いにくく、図と点名の補足が必要だった。球面上の例では辺が大円の弧であることも明記した。
- 算術平均: 同じ種類の量を同じ単位へそろえる条件と、記号 $\bar{x}$ の読みが不足していた。
- 等号の推移律: 一般の関係を定義する集合と、初出の難しい語の説明が不足していた。
- 学年を指定した三記事: 初回修正後にも、見出しや本文の一部に対象学年後または配当表外の漢字のルビ漏れが残ったため、記事全体を再度棚卸しした。

これらは記事固有の数学的レビューが引き続き必要であることを示す。指南書だけで公開品質を自動的に保証するものではないが、レビュー対象を共通形式へ揃える役割は果たしている。

## 指南書へ反映した改善

試作時に複数の担当が迷った点は、個別記事だけでなく指南書へ反映した。

- `prerequisites: []` の意味と、未確定の前提概念を成果報告へ返す手順を明記した。
- `readingLevel` を指定・省略する判断と、数学的定義を学年に合わせて不正確に狭めてはならないことを明記した。
- validatorではルビの構文を検査できても、学年別の網羅性は判定しないことと、公式配当表による最終照合を明記した。
- 例題の見出しと「問題・考え方・解答」の標準形を具体化した。
- ギリシャ文字や装飾付き記号の初出では読みを示すことを追加した。
- 幾何の証明で位置関係を文章だけでは一意に示せない場合、静止図を付ける方針を追加した。
- 外部SVG資産を静的・自己完結に保つための禁止要素と、公開前のソース確認を追加した。
- 重要語句は太字へ絞り、ルビ付き重要語は `strong="true"` で安全に強調する仕様を追加した。
- 下線はリンクと誤認されやすいため現時点では採用せず、まとまった注意には `callout` を使う方針を明記した。

## カタログへ移す場合の前提候補

fixtureでは空配列にしているが、公開カタログへ移す前には、実在する概念IDを確認して次の候補を検討する。

| 記事 | 前提候補 | 理由 |
| --- | --- | --- |
| 偶数と奇数 | 整数、整数の除法と余り | 定義に整数と余りを使うため |
| 三角形の内角の和 | 角、一直線の角、平行線と錯角 | 定理の条件と証明に使うため |
| 算術平均 | 加法、除法、データと単位 | 公式と例題の計算に使うため |
| 等号の推移律 | 等号、集合と関係 | 一般の推移性を述べるため。絶対値は反例だけに使うため、本文で説明するか関連概念とする |

## 判定

指南書は、分野と記事種別が異なる下書きを共通の構成・記法で作らせる入力として利用できる。ただし、数学的な範囲、定理の条件、統計の単位、論理の対象範囲は、独立した内容レビューを省略できない。

この四記事は公開用の完成記事ではなく、指南書やレンダラーを変更したときの回帰確認用サンプルとして残す。
